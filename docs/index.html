About This Benchmark Suite

Single-Core & Hybrid Core-Class Policy

Every entry runs strictly single-threaded (num_threads=1, OMP_NUM_THREADS=1) pinned to a single logical CPU. On heterogeneous / big.LITTLE CPUs (Intel P/E/LP-E, AMD Zen/Zen-c, ARM big.LITTLE, Apple Silicon P/E), scripts/run_bench.py --all-core-classes detects and pins each core class separately so every microarchitecture is ranked independently.

Strict Numerical Verification

Every run's binary .raw output is verified against stock ngspice-47 golden waveforms. SAR ADC decks additionally verify bit-exact digital output codes across every conversion cycle (16/16 codes on the hero test) and EOC timing (<500 ps). -ffast-math or physics approximations that fail verification are marked FAIL.

Open-Source Circuits & PDK

Models use the official open-source GlobalFoundries 180nm MCU PDK (wafer-space/gf180mcu git submodule). Circuits are real post-PEX mixed-signal netlists from aicdb (12b SAR ADC, 3-ch TI 12b SAR+PLL, 150 MHz ring PLL, 16b switched-cap SDM, and a 1,000-design × 16-PVT op-amp bundle).
